# Weather Dashboard

A Flutter weather dashboard that uses the public, keyless [Open-Meteo API](https://open-meteo.com/).

Features:
- Current temperature and feels-like temperature
- Weather condition and wind speed
- Seven-day forecast
- Dhaka, Chattogram, Rajshahi, and Sylhet location selector
- Pull-to-refresh and error handling

Run with:

```bash
flutter pub get
flutter run
```
